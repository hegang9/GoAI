# AGENTS.md

## 模块职责

- 本目录提供“启动前依赖体检”命令，用来检查 `config/config.toml` 指向的 MySQL 与 Redis 是否可达。
- 输出面向开发者阅读，重点是明确的 `OK/FAIL/INFO` 结果和可执行的修复提示。

## 变更约束

- 继续从项目根配置读取连接信息，不要引入与主服务不同步的独立配置来源。
- 失败场景保持快速退出和明确 exit code，不要吞掉连接错误。
- CLI 输出保持简洁稳定，避免把调试日志、堆栈或框架内部错误直接暴露给日常使用者。

## 验证

- 修改后运行 `go test ./test/... -v`；若入口行为变动明显，再补一次 `go run ./cmd/checkdeps` 的人工冒烟验证。
