# AGENTS.md

## 模块职责

- 本目录封装 MCP 客户端初始化、握手、健康检查和工具调用，提供给示例 CLI 复用。
- 生产 MCP 集成并不直接复用这里；这里保持为演示/调试客户端，对协议流程做薄封装。

## 变更约束

- 保持对 MCP 协议对象的薄封装，不要把业务规则硬编码进客户端层。
- 初始化顺序要完整：创建传输、`Initialize`、再执行 `Ping` 或工具调用。
- 返回错误时保留上下文；新增便捷方法时不要绕开通用 `CallTool` 的协议约束。
- `GetToolResultText` 要继续容忍非文本内容，只提取 `mcp.TextContent`，不要假设服务端永远只回单一文本块。

## 验证

- 在 `cmd/mcp/` 目录下运行 `go test ./...`；若变更了握手或工具调用流程，再补充与服务端联调验证。
