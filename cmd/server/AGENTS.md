# AGENTS.md

## 模块职责

- `cmd/server` 是后端主入口，只负责 `bootstrap.New()`、启动 HTTP 服务、监听退出信号和优雅关闭。

## 变更约束

- 入口保持瘦身；新增依赖装配、路由拼接或资源关闭顺序调整时，优先修改 `internal/bootstrap`。
- 信号处理和关闭超时要保持明确，避免把资源释放逻辑散落到多个入口文件。
- 日志应描述启动/退出阶段的重要节点，但不要在入口重复记录下层已经覆盖的细节。
- 不要在这里顺手启动或探测 MCP 服务；独立 MCP 进程是否可用应由调用链路按需处理，而不是让主服务入口承担耦合。

## 验证

- 入口修改后至少运行 `go test ./test/... -v`，并确认服务仍能从根目录读取 `config/config.toml`。
