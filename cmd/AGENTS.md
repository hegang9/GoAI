# AGENTS.md

## 模块职责

- `cmd/` 只放可执行入口和启动参数，不承载业务规则与持久化细节。
- 每个子目录都应保持“薄入口”风格：装配、启动、退出；业务行为落到 `internal/`。

## 变更约束

- 不要在 `main.go` 里复制 `bootstrap` 中已经存在的依赖装配逻辑。
- 新增入口时先判断是否应复用现有模块，避免把一次性脚本长期留在生产目录。
- `cmd/mcp` 是独立 Go module；涉及它的改动要显式考虑模块边界、依赖和运行方式。

## 验证

- 入口行为变化后，至少执行对应子目录的编译或测试命令，确认启动路径没有被破坏。
