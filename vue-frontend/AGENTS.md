# AGENTS.md

## 模块职责

- 本目录承载 Vue 3 前端，负责登录注册、菜单导航、AI 对话和图片识别页面。

## 变更约束

- 前端继续通过 `/api` 代理访问后端，鉴权依赖 `localStorage` 中的 `token`；改接口契约时要同步检查后端信封结构。
- 优先复用现有路由、API 客户端和 Element Plus 组件风格，不要为单页功能复制新的请求封装层。
- 页面改动要兼顾桌面与移动端，避免只在宽屏下可用。

## 验证

- 前端改动后在 `vue-frontend/` 目录运行 `npm run lint`；交互明显变化时再补充一次手动页面检查。
