# AGENTS.md

## 模块职责

- `router/` 维护前端路由表、页面懒加载关系和全局鉴权守卫。
- 路由层只负责导航决策，不承载页面业务逻辑、网络请求或组件状态同步。

## 变更约束

- 继续用 `meta.requiresAuth` 驱动鉴权守卫，避免把登录校验散落到各个 `views/` 页面。
- 路径、重定向、页面命名或懒加载目标变化时，同步检查 `Menu.vue` 导航入口、浏览器直达和未登录跳转。
- 不要从路由文件导入 `components/`、`composables/` 或页面内部状态；路由只应引用页面组件和鉴权所需的最小 token 读取。
- 新增受保护页面时必须显式标记 `meta.requiresAuth`，公开页面则保持跳转语义清晰。

## 验证

- 路由改动后运行 `npm run lint`，并手动验证未登录访问受保护路由会被重定向到 `/login`。
