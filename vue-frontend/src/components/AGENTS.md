# AGENTS.md

## 模块职责

- `components/` 存放可复用 UI 组件，是 UI 微调的最小着力点。
- 根级组件如 `GradientBackground.vue` 提供跨页面展示能力，子目录按领域继续细分为 `auth/` 与 `chat/`。

## 变更约束

- 组件层应尽量保持纯展示：通过 `props` 输入数据，通过 `emits` 或 slot 输出交互意图。
- 不要在组件内直接改路由守卫、复制请求封装、维护页面级会话状态或发起业务链路请求。
- 共享外观优先引用 `assets/styles/` 中的 CSS 变量和类名，避免局部硬编码破坏视觉一致性。
- 组件内部只保留与渲染强相关的轻量逻辑；可复用副作用应下沉到 `composables/`。

## 验证

- 组件改动后运行 `npm run lint`，并检查所有复用该组件的页面。
