# AGENTS.md

## 模块职责

- 本目录实现 RabbitMQ 传输、消息发布器和消费者，承接聊天消息的异步落库链路。

## 变更约束

- 队列载荷结构要与领域消息保持稳定映射，避免因 JSON 字段变更导致历史消费者/生产者不兼容。
- `Publisher` 继续只做序列化和发布，`Consumer` 继续只做反序列化和回调转发，不要把仓储逻辑写死在这里。
- 新增重试、死信或确认机制时，先明确是否属于基础设施职责，并同步审视启动与关闭路径。

## 验证

- 消息链路改动后运行 `go test ./test/... -v`，并确认会话消息持久化不会回归为同步阻塞路径。
