# AGENTS.md

## 模块职责

- 本目录负责 MySQL/GORM 连接、PO 定义、自动迁移和仓储实现。

## 变更约束

- 继续把数据库表结构和 GORM tag 收敛在 PO 层，领域实体与应用层对象不要混用 GORM 模型。
- 仓储要把底层未命中错误翻译为领域错误，例如用户仓储返回 `domain/user.ErrNotFound`。
- 连接池参数、迁移行为和查询排序变更前，要先检查启动路径与历史回放是否受影响。
- 不要从仓储层直接依赖控制器、DTO 或应用服务；基础设施只实现端口。

## 验证

- 持久化逻辑改动后运行 `go test ./test/... -v`，重点关注会话、用户和架构相关测试。
