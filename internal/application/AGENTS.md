# AGENTS.md

## 模块职责

- 应用层负责用例编排：组织领域对象、调用端口、处理流程和错误码，不直接绑定 Gin、GORM、Redis 或外部 SDK。

## 变更约束

- 应用服务输出面向上层的视图对象或 `code.Code`，不要把 HTTP DTO 或数据库 PO 泄漏到这一层。
- 跨模块协作时优先复用已有服务边界，不要把多个业务场景硬塞进单个“万能服务”。
- 日志聚焦用例节点和失败原因，避免在应用层重复打印底层已经完整记录的低价值噪声。

## 验证

- 应用层改动后运行 `go test ./test/... -v`，必要时补充受影响基础设施目录的包级测试。
