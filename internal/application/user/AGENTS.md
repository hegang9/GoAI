# AGENTS.md

## 模块职责

- 本目录编排登录、注册、验证码发送与内部账号编号生成。

## 变更约束

- 继续以 `Email` 作为登录入口、`AccountNo` 作为内部身份标识；不要混淆两者职责。
- 注册流程要保持“邮箱唯一校验 -> 验证码校验 -> 生成唯一账号编号 -> 哈希密码 -> 落库 -> 发邮件 -> 签发 token”的顺序可追踪。
- `accountNoCache` 的并发语义要保守，任何优化都不能破坏唯一性保障或失败回滚路径。
- 默认昵称、验证码邮件前缀、账号编号邮件前缀若变更，需同步更新文档与上下游预期。

## 验证

- 用户流程改动后运行 `go test ./test/... -v`，重点关注注册、配置和 JWT 相关回归风险。
