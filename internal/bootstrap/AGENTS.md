# AGENTS.md

## 模块职责

- 本目录是组合根：负责读取配置、创建基础设施适配器、装配应用服务、挂载路由并管理生命周期。

## 变更约束

- 继续把装配逻辑集中在这里；不要把依赖创建散落回 `cmd/server`、控制器或应用服务中。
- 资源初始化与关闭顺序要成对审视：MySQL、Redis、RabbitMQ、HTTP 服务的依赖关系不能随意打乱。
- 常量如 `mcpBaseURL`、模型资源路径、队列名若改动，必须同步检查引用链路与 README。
- 这里可以知道所有层，但不应新增业务分支、鉴权规则或请求级条件判断。
- `mcpBaseURL` 当前硬编码为 `http://localhost:8081/mcp`；若改成配置项或其他地址，要同步更新调试文档和 `cmd/mcp` 的默认行为。
- 启动回放依赖 `chatReplayConfig.defaultModelType`；若把它设为 `"3"`，会把 MCP 可用性引入启动阶段，这类变更必须显式评估。

## 验证

- 装配或生命周期改动后运行 `go test ./test/... -v`，必要时补充实际启动一次 `go run ./cmd/server` 的冒烟验证。
