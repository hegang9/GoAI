# AGENTS.md

## 模块职责

- `internal/` 承载后端核心实现，遵循仓库已经固化的分层架构与端口适配模式。

## 分层约束

- 依赖方向保持 `interfaces -> application -> domain`、`infrastructure -> domain`，由 `bootstrap` 负责装配。
- 领域层继续保持无框架、无配置、无存储实现细节；接口层不直接操作持久化或第三方 SDK。
- 跨层协作优先通过领域端口和应用服务完成，不要用全局变量或隐式单例绕过边界。

## 变更约束

- 修改任一子层时，先判断该逻辑属于“业务规则、编排、适配、传输、装配”中的哪一层，再落到对应目录。
- 新增目录时延续现有命名和职责划分，避免制造“半应用层半基础设施层”的灰色模块。
