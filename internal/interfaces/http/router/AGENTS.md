# AGENTS.md

## 模块职责

- 路由目录负责 Gin 引擎初始化、分组、公开/鉴权路由挂载和 404/405 响应装配。

## 变更约束

- 保持路由树清晰：公开接口走 `/user`，鉴权接口复用统一 JWT 中间件组，不要到处重复 `Use()`。
- 新接口应放到语义正确的子分组，避免把聊天、文件、图片、TTS 混在一个散乱的路由文件里。
- `NoRoute` / `NoMethod` 的统一响应格式要稳定，避免和普通业务响应脱节。
- `/api/v1/file/*` 与 `/api/v1/ai/chat/*` 当前都属于鉴权域；挪出鉴权组会直接破坏按账号隔离的 RAG/MCP 流程。

## 验证

- 路由改动后运行 `go test ./test/... -v`，并至少手动检查一个新旧路由的访问路径。
