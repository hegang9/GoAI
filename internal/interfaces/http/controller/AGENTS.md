# AGENTS.md

## 模块职责

- 控制器负责解析请求、调用应用服务、把结果映射成 DTO 或统一 JSON/SSE 响应。

## 变更约束

- 保持控制器瘦身：不要在这里写注册、检索、存储、模型编排等业务逻辑。
- 需要 JSON 绑定的接口优先走 `httpx.Handler`，不要重复手写相同的绑定和错误响应代码。
- 文件、聊天、TTS、图片等控制器仍应只依赖 `Handlers` 聚合的应用服务，不要直接 new 基础设施对象。
- 文件上传继续从 multipart 字段 `file` 读取内容，删除与聊天模型选择继续通过 DTO 把 `filenames` / `modelType` 传到应用层。
- 文件和聊天控制器都依赖 JWT 中间件注入的 `accountNo`；路由或上下文字段变化会直接影响 RAG/MCP 账号隔离。

## 验证

- 接口行为改动后运行 `go test ./test/... -v`，并人工验证对应 HTTP 路由。
