Cursor 2.2 Browser Visual Editor / CSS Inspector 中文教程

这份教程面向第一次使用 Cursor Browser Visual Editor 的开发者。Cursor 官方更常使用 Design Mode、Browser Design sidebar、Browser layout and style editor 这些名称；本文把大家口头说的 CSS Inspector 作为同一类能力来讲。

下方“截图”是离线可读的界面示意图，不是官方截图。它用箭头标出你需要认识的区域，实际 Cursor UI 可能随版本微调。

一、先理解它能做什么

Browser Visual Editor 是 Cursor Agent 浏览器能力的一部分。你可以在浏览器里点选页面元素， 用右侧设计面板调布局、尺寸、颜色、圆角、阴影、透明度等视觉属性，也可以直接用自然语言告诉 Agent “把这个按钮改成列居中”“让这块间距更大”。

关键点是：视觉编辑先发生在 Browser 预览里，点击 Apply 后，Cursor 才会让 Agent 把这些变化翻译成代码库里的实际修改。

推荐心智模型：它不是 Chrome DevTools 的替代品，而是“能把可视化调整落回源码的设计侧栏”。

二、进入 Design Mode

启动你的前端项目

例如本项目可以进入 vue-frontend 后运行 npm run serve，确保页面能在本地浏览器访问。

让 Cursor Browser 打开目标页面

在 Agent 中让 Cursor 打开本地地址，或在 Cursor 的 Browser pane / Agents Window 内打开你的页面。

打开 Design Mode

官方文档明确给出的快捷键是 macOS 的 Cmd + Shift + D。Windows 用户建议在 Cursor 的快捷键设置或命令面板里搜索 Design Mode / Browser Design，以本机显示为准。

点选页面元素并调整

点击目标元素后，观察左侧组件树、页面选中框和右侧 CSS Inspector / Design sidebar 是否同步变化。

四、CSS Inspector 各组件怎么用

Browser 顶部栏
用来确认当前页面地址、刷新页面、查看是否处于 Design Mode。先确认 URL 是你要编辑的页面，否则点选到的元素会来自错误页面。
Design Mode 开关
打开后才能用设计方式点选元素、查看设计侧栏并进行可视化调整。关闭后更接近普通浏览页面，适合验证交互。
页面选中框
点击页面元素后出现的高亮边框。它告诉你当前正在编辑哪一个 DOM / 组件。若选错了，先重新点击目标元素，不要急着改 CSS。
Component Tree / DOM Tree
展示页面结构和组件层级。适合处理“点不到内部元素”或“不确定这个按钮属于哪个组件”的情况。选择树上的节点后，右侧面板会跟着更新。
Layout / Position
调整布局方式，例如 display、flex-direction、justify-content、 align-items、grid 配置和元素顺序。按钮内容要“列居中”时，重点看这里。
Size & Spacing
调整宽高、内边距、外边距。适合处理按钮太窄、卡片间距不均、输入框高度不一致等问题。
Color / Theme
选择颜色、设计系统 token 或测试浅色/深色主题下的效果。长期维护时优先使用项目已有 token，不要随手写散落的硬编码颜色。
Appearance
调整圆角、阴影、透明度、边框等外观属性。它适合微调视觉质感，但不要在没有设计标准的情况下把每个元素都调成不同风格。
Props / State
对 React 组件，Cursor 可能暴露 props 或状态，用来快速切换 variant、loading、disabled 等状态。Vue 项目中不一定有同等程度的组件 props 可视化能力。
Prompt 输入
选中元素后可以用自然语言描述目标，例如“让这个按钮内容按列方向居中，宽度保持 100%”。适合你知道目标但不想手动找每个 CSS 属性时使用。
Apply
把浏览器中的视觉修改交给 Agent 落到源码。点击前先确认预览正确；点击后再检查代码 diff，因为 Agent 可能选择内联样式、组件 class 或 scoped CSS 等不同实现路径。

五、实战：把按钮调整为列居中

选中按钮

打开登录页，进入 Design Mode，点击“登录”按钮。确认页面上出现选中框，组件树中也定位到按钮节点。

在 Layout 中设置方向

找到 display / flex 相关区域，把方向设为 column， 并让 justify-content 与 align-items 都保持 center。

保持尺寸不变

在 Size 区确认按钮宽度仍是 100%，高度符合设计，例如 48px。

Apply 后检查源码

点击 Apply 后，让 Agent 修改代码。最后检查 diff，优先接受“给目标按钮加专用 class，并在 scoped CSS 中写布局”的实现， 避免影响页面里所有 Element Plus 按钮。

六、常见问题

为什么我点了元素，代码没有变？

可视化调整只是预览。需要点击 Apply，Cursor 才会让 Agent 把修改写回代码库。

为什么 Windows 快捷键和教程不一样？

官方文档明确写出的是 macOS 快捷键。Windows 上以 Cursor Keybindings 或命令面板搜索到的命令为准。

为什么我看不到某些面板？

可能是当前不在 Agents Window 的 Browser 中，或企业策略禁用了 browser features。先确认 Cursor 版本和工作区策略。

为什么 Vue 项目没有 React props/state？

官方提到 React fiber props 的上下文捕获。Vue 组件不一定展示同等信息，因此以 DOM、computed styles 和源码 diff 为主。

安全提醒：Browser 状态会按 workspace 持久化，可能包含 cookies、localStorage、sessionStorage、IndexedDB。 不要在不可信站点上随意开启自动运行或让 Agent 操作敏感账户。

七、建议工作流

  • 先用 Browser Visual Editor 快速找到合适视觉结果。
  • 再点击 Apply 生成代码变更。
  • 检查 diff：样式是否只作用于目标组件，是否破坏设计系统约定。
  • 运行项目校验：前端项目至少运行 lint；视觉问题还需要手动刷新页面确认。
  • 把稳定的样式沉淀到 class / scoped CSS / token 中，不要长期依赖临时内联样式。
